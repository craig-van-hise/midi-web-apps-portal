# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives

### 1.1 Summary of Objectives

We are executing **Chunk 3 (Expanded Sequencer Interactivity & History)** of the master backlog for the **VV | MIDI Chord Notator & Sequencer** suite (`src/plugins/chord-notator/`). Three critical functional defects currently affect interactivity, audio sustain, and history tracking:

1. **Marquee Selection Bounding-Box Zeroing Bug (`StepSequencer.tsx`):** In expanded mode (`isExpanded === true`), dragging a marquee selection box over noteheads renders the visual blue box correctly but fails to select any intersecting notes upon release.


2. **Infinite Sustain on Transposition (`NotationCanvas.tsx` & `StepSequencer.tsx`):** Transposing notes via keyboard commands (e.g., Arrow Up/Down with Alt/Cmd modifiers) or transformation toolbar buttons causes the newly transposed pitches to sustain infinitely without sending a Note Off MIDI message. As explicitly noted, this bug occurs on **both** the main notation canvas (`NotationCanvas.tsx`) and the step sequencer (`StepSequencer.tsx`).
3. **Missing Transposition History Snapshots (`StepSequencer.tsx`):** While the timeline sequencer's Undo/Redo stack (`seqUndoStack` / `seqRedoStack`) correctly captures manual note additions and deletions, it fails to record state snapshots when a selected step is transposed via transformation commands (`APP_TRANSFORM`), preventing users from undoing chord transpositions.



### 1.2 Current Technical State & Root Cause Analysis

* **Why Marquee Selection Fails (`StepSequencer.tsx`):**
* In `handlePointerUp` (lines 508–510 of `StepSequencer.tsx`), the code executes:


```tsx
if (marqueeRef.current) {
  marqueeRef.current.classList.add('hidden');
  const marqueeRect = marqueeRef.current.getBoundingClientRect();

```


* In DOM browsers and JSDOM, adding `hidden` (`display: none`) immediately collapses the element's bounding box to **all zeros** (`left: 0, top: 0, width: 0, height: 0`) before `getBoundingClientRect()` is called. Consequently, the intersection check against note hitboxes (`elRect.right < marqueeRect.left`, etc.) always evaluates to `false`, leaving `intersectingPitches` empty.




* **Why Transposition Audio Sustains Infinitely (`NotationCanvas.tsx` & `StepSequencer.tsx`):**
* In `NotationCanvas.tsx`, transformation functions (`applyChromaticShift`, `applyDiatonicShift`, `applyPcsRotation`) invoke naked `audioEngine.noteOn(noteStr, velocity)` calls to audition transposed pitches. They rely on `APP_TRANSFORM_OFF` (key-up / button-release) to send `releaseNote`. However, when transposing via keyboard shortcuts or rapid button clicks, `APP_TRANSFORM_OFF` frequently fails to fire or arrives out of order, leaving voices stuck on.
* To guarantee zero stuck notes, all transposition previews across both `NotationCanvas.tsx` and `StepSequencer.tsx` must route through a strict 500ms self-terminating timer (`playPreviewNotes(noteStrings, true)`), which cancels previous timers and guarantees `audioEngine.releaseNote(noteStr)` execution.




* **Why Timeline Undo/Redo Misses Transpositions (`StepSequencer.tsx`):**
* When an `APP_TRANSFORM` event occurs while a step is selected (`selectedStepRef.current !== null`), `NotationCanvas.tsx` computes the transposed pitches and broadcasts a `MIDI_MESSAGE_RECEIVED` event with `refresh: true` to update the active step in `StepSequencer.tsx`. Because `StepSequencer.tsx` does not listen to `APP_TRANSFORM`, `commitSeqState()` is never called prior to the sequence mutation.

## 2. Technical Decisions & Dependencies

### 2.1 Architectural Decisions & Zero-Drift Alignment

* **Order of Operations Fix for Marquee Bounding Box:** We must read `marqueeRef.current.getBoundingClientRect()` **before** adding the `hidden` class in `handlePointerUp`.


* **Mandatory 500ms Timer for Transposition Previews:** We replace all naked `audioEngine.noteOn(...)` calls inside `applyChromaticShift`, `applyDiatonicShift`, and `applyPcsRotation` in `NotationCanvas.tsx` with `playPreviewNotes(transposedStrings, true, uiVelocityRef.current)`. This clones the proven 500ms self-terminating audio preview pattern used in `StepSequencer.tsx`.


* **Pre-Transform Snapshot Hook in Sequencer:** We introduce a window event listener for `APP_TRANSFORM` in `StepSequencer.tsx` that calls `commitSeqState()` whenever a step is active (`selectedStepRef.current !== null`), capturing a deep-cloned JSON snapshot (`JSON.parse(JSON.stringify(sequenceRef.current))`) before `refresh: true` modifies the sequence.



### 2.2 Pseudo-Code Specifications

#### Marquee Intersection Correction (`StepSequencer.tsx`)

```typescript
const handlePointerUp = (e: React.PointerEvent) => {
  if (!isExpanded || !dragTracker.current.isDragging) return;
  dragTracker.current.isDragging = false;
  try { e.currentTarget.releasePointerCapture(e.pointerId); } catch(err) {}

  if (marqueeRef.current) {
    // 1. CAPTURE GEOMETRY BEFORE HIDING THE DOM NODE
    const marqueeRect = marqueeRef.current.getBoundingClientRect();
    marqueeRef.current.classList.add('hidden'); // Hide after reading rect

    const startStep = dragTracker.current.startStep;
    if (startStep !== -1 && sequence[startStep]) {
      const notesInStep = document.querySelectorAll(`div[data-seq-step="${startStep}"]`);
      const intersectingPitches: number[] = [];

      notesInStep.forEach(el => {
        const elRect = el.getBoundingClientRect();
        const intersects = !(
          elRect.right < marqueeRect.left ||
          elRect.left > marqueeRect.right ||
          elRect.bottom < marqueeRect.top ||
          elRect.top > marqueeRect.bottom
        );
        if (intersects) {
          const pitch = parseInt(el.getAttribute('data-seq-note') || '', 10);
          if (!isNaN(pitch)) intersectingPitches.push(pitch);
        }
      });

      if (intersectingPitches.length > 0) {
        updateActiveNotes(sequence[startStep].notes, true, false, intersectingPitches);
      }
    }
  }
};

```

#### Transposition Audio Preview Timer (`NotationCanvas.tsx`)

```typescript
// Inside applyChromaticShift, applyDiatonicShift, and applyPcsRotation:
if (listenModeRef.current && isUiClick) {
  const transposedStrings = Array.from(selectedNoteIds.current)
    .map(id => activeNotes.current.find(n => n.id === id)?.note)
    .filter((n): n is number => typeof n === 'number')
    .map(pitch => Tone.Frequency(pitch, "midi").toNote());

}

```

      commitSeqState();
    }
  };
