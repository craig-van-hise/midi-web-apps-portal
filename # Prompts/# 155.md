# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives

### 1.1 Summary of Objectives

The **VV | MIDI Chord Notator & Sequencer** suite (`src/plugins/chord-notator/`) currently suffers from a destructive **"Katamari" voice-catching and erasure defect** when a user transposes an individual voice across another existing voice in the chord.

When a lower voice is transposed upward and reaches unison with an upper voice (e.g., transposing C4 / `60` up to E4 / `64`), two distinct failures occur:

1. **Voice Erasure on the Notation Canvas (`NotationCanvas.tsx`):** When `{ refresh: true, notes }` arrives, `NotationCanvas.tsx` uses `.find((item: any) => item.note === pitch)` to map pitches back to note objects. Because `.find()` matches by raw MIDI pitch number, two unison voices at `64` are assigned the **exact same ID**. Subsequently, `recalculateLayout()` executes `if (!allNotes.some(existing => existing.id === n.id)) allNotes.push(n);`, discarding the duplicate ID and erasing the second voice from the visual staff.


2. **The "Katamari" Multi-Voice Trap (`StepSequencer.tsx` & `NotationCanvas.tsx`):** Once multiple unison voices share the same ID (or when selection matching greedily checks `targetSelection.includes(note.note)`), any keyboard or toolbar transposition (`ArrowUp`/`ArrowDown`) moves **all** voices sitting at that pitch together. As the transposing blob travels upward through the chord, it catches and traps every voice it touches.



We must upgrade `NotationCanvas.tsx` and `StepSequencer.tsx` to:

1. **Preserve Unique Voice IDs on Refresh:** Eliminate `.find(item => item.note === pitch)` inside the `{ refresh: true }` handler of `NotationCanvas.tsx` so every note object retains its unique `id` (`crypto.randomUUID()`) when pitches form true unisons.


2. **Enforce 1-to-1 Voice Selection Cardinality:** Ensure that selecting or crossing into a unison pitch only selects the specific voice instance being manipulated, allowing independent voices to traverse through one another without catching or merging unselected voices.


3. **Establish 1-to-1 Unison Highlighting in the Step Sequencer:** Update the note rendering loop in `StepSequencer.tsx` so that when only one instance of a doubled pitch is selected, only one notehead highlights in purple (`#aa3bff`), while the remaining unison noteheads render unselected.



### 1.2 Current Technical State & Root Cause Analysis

* **ID Clobbering in `NotationCanvas.tsx`:** In L531–L543 of `NotationCanvas.tsx`, the refresh handler executes:


```typescript
activeNotes.current = safePitches.map((pitch: number) => {
  const existing = notes.find((item: any) => (typeof item === 'object' ? item.note : item) === pitch);
  if (existing && typeof existing === 'object' && existing.id) {
    return { ...existing, note: pitch };
  }
  return { id: generateId(), note: pitch, ... };
});

```


When `notes` contains doubled pitches (`[64, 64, 67, 72]`), `.find(item => item.note === 64)` returns `notes[0]` for **both** instances of `64`. Both voices receive `notes[0].id`.


* **Deduplication in `recalculateLayout()`:** In L469–L474 of `NotationCanvas.tsx`, `recalculateLayout()` filters `allNotes`:


```typescript
assigned.forEach(n => {
  if (!allNotes.some(existing => existing.id === n.id)) {
    allNotes.push(n);
  }
});

```


Because both unison voices now share `notes[0].id`, `allNotes` rejects the second voice, erasing it from the staff.


* **Greedy Selection Highlighting in `StepSequencer.tsx`:** In L728 of `StepSequencer.tsx`, selection highlighting is evaluated as:


```typescript
const isNoteSelected = isStepSelected && selectedNotes?.includes(n.note);

```


When two voices share `n.note === 64`, both noteheads highlight purple (`#aa3bff`), causing visual confusion and multi-voice toggling on click.

## 2. Technical Decisions & Dependencies

### 2.1 Architectural Decisions & Zero-Drift Alignment

* **Direct ID Preservation in Refresh Handler (`NotationCanvas.tsx`):** We replace `.find(item => item.note === pitch)` in `NotationCanvas.tsx` with a direct 1-to-1 mapping over `notes`. Every incoming note object preserves its existing `.id` (or generates a new UUID if plain number), ensuring zero ID collisions when pitches are doubled.


* **1-to-1 Pitch-to-Voice Cardinality Matching:** When external selection arrays (`targetSelection`) are processed in `NotationCanvas.tsx`, we use `.findIndex` with `!newSelectedIds.has(n.id)` so each target pitch claims **at most one** unselected voice ID.


* **1-to-1 Visual Highlighting in `StepSequencer.tsx`:** In the note rendering loop of `StepSequencer.tsx`, we compare the count of `n.note` in `selectedNotes` against the count of `n.note` appearing before index `i` in `renderedNotes`, ensuring only the selected number of unison noteheads highlight in purple.



### 2.2 Mathematical Formulas & Pseudo-Code Specifications

#### 1-to-1 Voice Cardinality Selection Matching (`NotationCanvas.tsx`)

$$\forall p \in \text{targetSelection}, \quad \exists! \, v \in \text{activeNotes} \text{ s.t. } v.\text{note} = p \land v.\text{id} \notin \text{newSelectedIds}$$

```typescript
// Replaces greedy targetSelection matching inside handleMidiMessage in NotationCanvas.tsx:

if (Array.isArray(targetSelection)) {
  selectedNoteIds.current.clear();
  if (targetSelection.length > 0) {
    const newSelectedIds = new Set<string>();
    const availableNotes = [...activeNotes.current];
    
    targetSelection.forEach(targetPitch => {
      // Find the first matching voice that hasn't already been claimed
      const matchIdx = availableNotes.findIndex(
        n => n.note === targetPitch && !newSelectedIds.has(n.id)
      );
      if (matchIdx !== -1) {
        newSelectedIds.add(availableNotes[matchIdx].id);
        lastSelectedNoteId.current = availableNotes[matchIdx].id;
      }
    });
    
    selectedNoteIds.current = newSelectedIds;
    const selectedPitches = activeNotes.current
      .filter(n => newSelectedIds.has(n.id))
      .map(n => n.note);
    setSelectedNotes?.(selectedPitches);
  } else {
    lastSelectedNoteId.current = null;
    setSelectedNotes?.([]);
  }
}

```

#### ID-Preserving Refresh Mapping (`NotationCanvas.tsx`)

```typescript
// Inside handleMidiMessage when refresh === true in NotationCanvas.tsx:

if (notes) {
  const cleanedNotes = notes
    .map((item: any) => {
      const pitch = Number(typeof item === 'object' ? item.note : item);
      if (isNaN(pitch) || pitch < 21 || pitch > 108) return null;
      if (typeof item === 'object' && item !== null && item.id) {
        return {
          ...item,
          note: pitch,
          isTreble: pitch >= splitPointRef.current,
          sourceMidi: item.sourceMidi ?? pitch
        };
      }
      return {
        id: generateId(),
        note: pitch,
        stepOffset: 0,
        accidental: null,
        isTreble: pitch >= splitPointRef.current,
        sourceMidi: pitch
      };
    })
    .filter((item: any): item is ActiveNoteData => item !== null);

  activeNotes.current = cleanedNotes;
}

```

#### 1-to-1 Unison Highlighting (`StepSequencer.tsx`)

```typescript
// In StepSequencer.tsx note rendering loop (renderedNotes.map((n, i) => ...)):

const isStepSelected = selectedStep === idx;
const selectedCount = (selectedNotes || []).filter(p => p === n.note).length;

  .slice(0, i)
  .filter((prevNote: any) => prevNote.note === n.note).length;
```
