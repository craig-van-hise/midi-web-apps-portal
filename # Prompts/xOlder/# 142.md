# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
In the Chord Notator module (`src/plugins/chord-notator/`), the 12-bar timeline (`StepSequencer.tsx`) suffers from severe interaction bugs because it deviated from the established methods used in the main `NotationCanvas.tsx`.

1. **Arrow Key Transposition vs. Traversal Bug:** Raw `ArrowUp` and `ArrowDown` keys are incorrectly transposing notes on the timeline. Parity with `NotationCanvas.tsx` dictates that raw arrow keys must **only traverse selection** through the chord's voices. Transposition must strictly require a modifier key (`Shift`, `Meta`, `Ctrl`, or `Alt`).
2. **Write Mode "50% Note Drop" Bug:** Clicking to enter a note in Write Mode occasionally fails to register. This is because the click handler relies on an async React hover state (`activeGhostBar`), creating a race condition. Note entry must be calculated synchronously on `onPointerDown` using the exact `e.clientY` math, identical to `NotationCanvas.tsx`.
3. **Timeline Undo/Redo Corruption:** Pressing `Cmd+Z` rolls through corrupted or seemingly random old sequence states. This occurs because timeline edits are either failing to trigger history commits or are pushing shallow references of the `sequence` array instead of strict deep clones.

## 2. Technical Decisions & Architectural Fixes

### 1. Arrow Key Selection Traversal (Ported from NotationCanvas)
Raw arrow keys must traverse the selected notes. Transposition requires modifiers.
```tsx
// Inside handleKeyDown in StepSequencer.tsx
if (e.key === 'ArrowUp' || e.key === 'ArrowDown') {
  const delta = e.key === 'ArrowUp' ? 1 : -1;

  if (e.shiftKey || e.metaKey || e.ctrlKey || e.altKey) {
    e.preventDefault();
    // Transposition logic here... (e.g. applyChromaticShift / applyDiatonicShift)
  } else {
    // SELECTION TRAVERSAL (Exact port from NotationCanvas.tsx)
    if (selectedNotes.length === 1) {
      e.preventDefault();
      const currentPitch = selectedNotes[0];
      const activeBarNotes = sequenceRef.current[selectedStepRef.current]?.notes || [];
      const allPitches = activeBarNotes.map((n: any) => n.note).sort((a: number, b: number) => a - b);
      
      const currentIndexInSorted = allPitches.indexOf(currentPitch);
      if (currentIndexInSorted === -1) return;
      
      const nextIndexInSorted = (currentIndexInSorted + delta + allPitches.length) % allPitches.length;
      const nextPitch = allPitches[nextIndexInSorted];
      
      updateActiveNotes(activeBarNotes, true, false, [nextPitch]);
      playPreviewNotes([Tone.Frequency(nextPitch, "midi").toNote()], true);
    }
  }
}

```

### 2. Synchronous Write Mode Click Calculation

Remove reliance on `activeGhostBar` or `ghostData` state for note insertion. Calculate the target pitch synchronously during the `onPointerDown` event.

```tsx
// Inside onPointerDown of data-staff-area={idx}
if (isWriteMode && isExpanded) {
  e.preventDefault();
  e.stopPropagation();

  // Synchronous calculation bypassing React state race conditions
  const rect = e.currentTarget.getBoundingClientRect();
  const mouseY = e.clientY - rect.top;
  if (mouseY < 0 || mouseY > rect.height) return; // Out of bounds guard

  const staffCenterY = rect.height / 2;
  const stepHeight = currentStaffSpace / 2;
  const stepOffset = Math.round((staffCenterY - mouseY) / stepHeight);

  const { midiNote: targetNote, accidental: calcAcc } = calculateWriteModePitch(
    stepOffset, keySignature, accidentalOverride, lut
  );

  commitSeqState(); // Commit history BEFORE mutation
  
  const newNoteObj = {
    id: generateId(),
    note: targetNote,
    stepOffset,
    accidental: calcAcc,
    isTreble: targetNote >= 60,
    sourceMidi: targetNote
  };

  setSequence((prev: any[]) => {
    const next = [...prev];
    const currentNotes = next[idx]?.notes || [];
    if (!currentNotes.some((n: any) => n.note === targetNote)) {
      const updatedNotes = [...currentNotes, newNoteObj];
      next[idx] = { 
        notes: updatedNotes, 
        symbol: getChordSymbol(updatedNotes.map((n: any) => n.note), keySignature, lut) 
      };
    }
    return next;
  });

  playPreviewNotes([Tone.Frequency(targetNote, "midi").toNote()], true);
}

```

### 3. Strict Deep-Clone History Stack

Ensure the timeline history stack deep-clones the sequence to prevent object reference corruption.

```tsx
const commitSeqState = () => {
  // STRICT DEEP CLONE to prevent reference mutations corrupting history
  seqUndoStack.current.push(JSON.parse(JSON.stringify(sequenceRef.current)));
  seqRedoStack.current = [];
  if (seqUndoStack.current.length > 50) seqUndoStack.current.shift();
};

```
