
# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives
In the Chord Notator module (`src/plugins/chord-notator/`), the 12-bar timeline (`StepSequencer.tsx`) currently exhibits a severe DOM targeting and coordinate mapping bug in Write Mode:

1. **DOM Attribute Misplacement & Ghost Note Hover Bug:** `data-step-index={idx}` is currently attached directly to the `<div className="h-10 ...">` chord symbol pill header rather than the outer step bar wrapper or inner staff canvas. Consequently, hover detection (`closest('[data-step-index]')`) returns `null` when hovering over the staff canvas, and **only triggers when hovering over the top chord pill header**.
2. **Y-Coordinate Projection Error:** When hovering over the chord pill header, `e.clientY` measures a position above the staff canvas. Calculating staff steps from this header position forces ghost noteheads to project down into the middle of the staff with a massive vertical error.
3. **Required Fix:** 
   - Move `data-step-index={idx}` up to the parent step bar column wrapper (`<div key={idx} id={`seq-bar-${idx}`} data-step-index={idx}>`).
   - Add a dedicated `data-staff-area={idx}` attribute directly to the staff system container (`<div data-staff-area={idx} className="flex-1 relative w-full h-full staff-canvas-area">`).
   - Attach pointer movement listeners directly to `data-staff-area={idx}`. Pointer events on this element fire **only** when the cursor is physically over the staff canvas area, completely isolating coordinates from the top $40\text{px}$ chord header.
4. **Additional Parity Requirements:** Fix ottava (`8va`/`15ma`) label placement (centered above/below chords), eliminate infinite audio sustain on Arrow key note transpositions via 500ms preview tracking, and relocate the Write Mode accidental toolbar outside the timeline card.

```tsx
  <div

    onPointerMove={(e) => {
      if (!isWriteMode || !isExpanded) return;
      const rect = e.currentTarget.getBoundingClientRect();
      const mouseY = e.clientY - rect.top;
      
      // Calculate exact staff center (Middle C / stepOffset = 0)
      const staffCenterY = rect.height / 2;
      const relativeY = staffCenterY - mouseY;
      const stepHeight = currentStaffSpace / 2;
      const stepOffset = Math.round(relativeY / stepHeight);
      const snappedY = staffCenterY - (stepOffset * stepHeight);

      const { midiNote, accidental: calculatedAcc } = calculateWriteModePitch(
        stepOffset,
        keySignature,
        accidentalOverride,
        lut
      );

      setActiveGhostBar(idx);
      setGhostData({ stepOffset, snappedY, midiNote, calculatedAcc });
    }}
    onPointerLeave={() => {
      if (activeGhostBar === idx) {
        setActiveGhostBar(null);
      }
    }}
    onPointerDown={(e) => {
      if (!isWriteMode || !isExpanded || !ghostData) return;
      e.preventDefault();
      e.stopPropagation();

      // Append pitch to active bar notes
      const targetNote = ghostData.midiNote;
      const newNoteObj = {
        id: generateId(),
        note: targetNote,
        stepOffset: ghostData.stepOffset,
        accidental: ghostData.calculatedAcc,
        isTreble: targetNote >= 60,
        sourceMidi: targetNote
      };

      setSequence((prev: any[]) => {
        const next = [...prev];
        const currentNotes = next[idx]?.notes || [];
        if (!currentNotes.some((n: any) => n.note === targetNote)) {
          const updatedNotes = [...currentNotes, newNoteObj];
          const pitches = updatedNotes.map((n: any) => n.note);
          const symbol = getChordSymbol(pitches, keySignature, lut);
          next[idx] = { notes: updatedNotes, symbol };
        }
        return next;
      });

      playPreviewNotes([Tone.Frequency(targetNote, "midi").toNote()], true);
    }}
  >
    {/* Ghost Notehead (Rendered strictly inside staff canvas area) */}
    {isWriteMode && activeGhostBar === idx && ghostData && (
      <div
        className="absolute pointer-events-none opacity-60 z-50 transition-none"
        style={{
          left: '50%',
          top: `${ghostData.snappedY}px`,
          transform: 'translate(-50%, -50%)'
        }}
      >
        {ghostData.calculatedAcc && (
          <span
            className="absolute"
            style={{
              left: `calc(-1.5 * ${currentStaffSpace}px)`,
              top: '50%',
              transform: 'translateY(-50%)',
              fontFamily: "'Bravura', sans-serif",
              fontSize: `${currentStaffSpace * 3}px`,
              color: '#aa3bff'
            }}
          >
            {ghostData.calculatedAcc}
          </span>
        )}
        <span
          style={{
            fontFamily: "'Bravura', sans-serif",
            fontSize: `${currentStaffSpace * 4.2}px`,
            color: '#aa3bff'
          }}
        >
          {SMuFL.noteheadBlack}
        </span>
      </div>
    )}

    {/* Staff Lines, Clefs, and Rendered Notes */}
  </div>
</div>

```

### Mathematical Formulas

#### Direct Staff Area Y-Snapping

When pointer events are attached directly to `.staff-canvas-area`, `e.currentTarget.getBoundingClientRect()` yields the exact bounding box of the staff system ($Y=0$ at the top edge of the staff area, $Y=\text{height}$ at the bottom edge):

$$\text{mouseY} = \text{e.clientY} - \text{rect.top}$$

$$\text{staffCenterY} = \frac{\text{rect.height}}{2}$$

$$\text{relativeY} = \text{staffCenterY} - \text{mouseY}$$

$$\text{stepHeight} = \frac{\text{currentStaffSpace}}{2}$$

$$\text{stepOffset} = \text{Math.round}\left(\frac{\text{relativeY}}{\text{stepHeight}}\right)$$

$$\text{snappedY} = \text{staffCenterY} - (\text{stepOffset} \times \text{stepHeight})$$
