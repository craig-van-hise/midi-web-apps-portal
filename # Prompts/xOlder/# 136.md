# Product Requirements Prompt (PRP) — [Status Marker] 🔵

## 1. Project Context & Objectives

In the Chord Notator module (`src/plugins/chord-notator/`), three specific functional and visual bugs remain in the 12-bar timeline (`StepSequencer.tsx`) and its interaction engine:

1. **Write Mode Ghost Note Y-Axis Mouse Offset Bug:** When hovering the mouse over the chord pill/header area at the top of a step bar, the purple ghost notehead renders down near the middle of the treble staff. This occurs because `StepSequencer.tsx` measures `clientY` relative to the bar's bounding box without subtracting the top 40px chord pill header (`h-10`), misaligning visual Middle C relative to the grand staff center.


2. **Ottava (`8va`/`15ma`) Label Placement Bug:** The `8va` marking currently renders *to the left* of noteheads (`8va O`) instead of positioned *above* the staff/chord. In `NotationCanvas.tsx`, ottava labels are centered horizontally (`left: 50%`, `-translate-x-1/2`) and positioned vertically above the highest note or below the lowest note.


3. **Key Command Transposition Audio Sustain Bug:** While clicking a note fires a 500ms preview, transposing selected notes via keyboard shortcuts (`ArrowUp`, `ArrowDown`, `Alt+ArrowUp`, etc.) triggers un-tracked `audioEngine.noteOn` calls without scheduling corresponding `releaseNote` timeouts. This causes transposed notes to sustain indefinitely.

## 2. Technical Decisions & Dependencies

### Component State & Dependencies (`StepSequencer.tsx`)

* **`activePreviews` (`useRef<Map<string, ReturnType<typeof setTimeout>>>`):** A mutable map ref tracking active playing pitch strings and their scheduled release timeouts to guarantee strict 500ms preview durations.


* **`currentStaffSpace` (number):** `isExpanded ? 11 : 5` (px per staff space).


* **`isWriteMode` (boolean):** State controlling Write Mode note insertion and ghost notehead tracking.


* **`accidentalOverride` (`'b' | 'bb' | 'n' | '#' | 'x' | null`):** Selected accidental modifier.



### Mathematical Formulas & Architectural Specifications

#### 1. Calibrated Grand Staff Y-Center & Mouse Ghost Note Math

When computing pointer Y relative to a timeline bar, account for the `40px` top chord pill header (`h-10`) so that visual Middle C aligns perfectly with $y = 0$:

$$\text{staffAreaHeight} = \text{rect.height} - 40\text{px}$$

$$\text{staffCenterY} = 40\text{px} + \left(\frac{\text{staffAreaHeight}}{2}\right)$$

$$\text{pointerY} = \text{clientY} - \text{rect.top}$$

$$\text{relativeY} = \text{staffCenterY} - \text{pointerY}$$

$$\text{stepOffset} = \text{Math.round}\left(\frac{\text{relativeY}}{\text{currentStaffSpace} / 2}\right)$$

$$\text{snappedY} = \text{staffCenterY} - \left(\text{stepOffset} \times \frac{\text{currentStaffSpace}}{2}\right)$$

```tsx
const snapTimelineGhostNote = (
  clientY: number,
  barElement: HTMLElement,
  currentStaffSpace: number,
  keySignature: string,
  accidental: AccidentalOverride,
  lut: any[]
) => {
  const rect = barElement.getBoundingClientRect();
  const HEADER_PILL_HEIGHT = 40; // h-10 header
  const staffAreaHeight = rect.height - HEADER_PILL_HEIGHT;
  const staffCenterY = HEADER_PILL_HEIGHT + (staffAreaHeight / 2);

  const pointerY = clientY - rect.top;
  const relativeY = staffCenterY - pointerY;
  
  const stepHeight = currentStaffSpace / 2;
  const stepOffset = Math.round(relativeY / stepHeight);
  const snappedY = staffCenterY - (stepOffset * stepHeight);

  const { midiNote, accidental: calculatedAcc } = calculateWriteModePitch(
    stepOffset,
    keySignature,
    accidental,
    lut
  );

  return { stepOffset, snappedY, midiNote, calculatedAcc };
};

```

#### 3. Unified Audio Preview Engine (`playPreviewNotes`)

All preview triggers (mouse clicks, selection changes, Write Mode entry, and key command transpositions) must route strictly through `playPreviewNotes`:

```tsx
const activePreviews = useRef<Map<string, ReturnType<typeof setTimeout>>>(new Map());

const playPreviewNotes = (noteStrings: string[], interrupt: boolean = true, velocity: number = 80) => {
  if (interrupt) {
    // 1. Clear all active timeouts and release pending notes
    activePreviews.current.forEach((timeoutId, noteStr) => {
      clearTimeout(timeoutId);
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
    });
    activePreviews.current.clear();
    try { audioEngine.releaseAll(); } catch(err) {}
  }

  const normalizedVelocity = velocity / 127;

  // 2. Trigger new noteOn events and schedule 500ms release NoteOff
  noteStrings.forEach(noteStr => {
    try { audioEngine.noteOn(noteStr, normalizedVelocity); } catch(err) {}
    const timeoutId = setTimeout(() => {
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
      activePreviews.current.delete(noteStr);
    }, 500); // Strict 500ms duration (1/4 note at 120 BPM)
    activePreviews.current.set(noteStr, timeoutId);
  });
};

```
