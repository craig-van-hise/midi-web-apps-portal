
# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
In the Chord Notator module (`src/plugins/chord-notator/`), expanding the 12-bar timeline (`StepSequencer.tsx`) in-situ currently suffers from Y-axis snapping miscalibrations in Write Mode, high-register note overflow, and missing ottava shifting (`8va`, `8vb`, `15ma`, `15mb`) that exists in the main notation canvas (`NotationCanvas.tsx`):

1. **Write Mode Pitch Register & Y-Snapping Bug:** Double-clicking into Write Mode on the timeline currently snaps ghost noteheads to an abnormally high octave register far above the grand staff, causing ghost notes and ledger lines to overlap the chord card pills.
2. **Missing Ottava (`8va`/`8vb`) Shifting:** Unlike `NotationCanvas.tsx`, `StepSequencer.tsx` lacks ottava range compression. Extreme high or low pitches rendered on the timeline blow out vertical space instead of applying $-7$/$-14$ (`8va`/`15ma`) or $+7$/$+14$ (`8vb`/`15mb`) shifts with SMuFL ottava labels.
3. **Accidental Toolbar Location:** The Write Mode accidental toolbar currently renders inside the timeline card, overlapping bars 1 and 2. It must be relocated **outside** the timeline card into the UI gap between `NotationCanvas` and `StepSequencer`.
4. **In-Situ Staff Scaling & Clef Column Width:** Notehead vertical positioning uses a hardcoded step multiplier (`MINI_STAFF = 5`), squishing expanded notes. The left clef column (`w-[45px]`) is too narrow, causing SMuFL clefs and braces to clip.
5. **Audio & Navigation Parity:** Chord pills must sustain playback on hold until pointer release; timeline note clicks must fire a clean 500ms preview; and Left/Right arrow navigation must preserve partial voice selections (top-down voice index matching) between bars.

### Mathematical Formulas & Algorithms

#### 1. Timeline Layout & Ottava Shifting Engine (`computeMiniLayout`)
Port the exact ottava shifting logic from `NotationCanvas.tsx` into `computeMiniLayout` in `StepSequencer.tsx`:

```tsx
const computeMiniLayout = (rawNotes: any[], staffSpace: number) => {
  const trebleNotesRaw = rawNotes.filter(n => n.isTreble);
  const bassNotesRaw = rawNotes.filter(n => !n.isTreble);

  let trebleShift = 0;
  let trebleLabel: { glyph: string; suffix: string } | null = null;
  if (trebleNotesRaw.length > 0) {
    const maxTrebleStep = Math.max(...trebleNotesRaw.map(n => n.stepOffset));
    const minTrebleStep = Math.min(...trebleNotesRaw.map(n => n.stepOffset));
    if (maxTrebleStep >= 25 && minTrebleStep - 14 >= -2) {
      trebleShift = -14; trebleLabel = { glyph: SMuFL.quindicesima, suffix: 'ma' };
    } else if (maxTrebleStep >= 18 && minTrebleStep - 7 >= -2) {
      trebleShift = -7; trebleLabel = { glyph: SMuFL.ottava, suffix: 'va' };
    }
  }

  let bassShift = 0;
  let bassLabel: { glyph: string; suffix: string } | null = null;
  if (bassNotesRaw.length > 0) {
    const minBassStep = Math.min(...bassNotesRaw.map(n => n.stepOffset));
    const maxBassStep = Math.max(...bassNotesRaw.map(n => n.stepOffset));
    if (minBassStep <= -22 && maxBassStep + 14 <= 2) {
      bassShift = 14; bassLabel = { glyph: SMuFL.quindicesima, suffix: 'mb' };
    } else if (minBassStep <= -15 && maxBassStep + 7 <= 2) {
      bassShift = 7; bassLabel = { glyph: SMuFL.ottava, suffix: 'vb' };
    }
  }

  const processGroup = (groupRaw: any[], shift: number, isTreble: boolean) => {
    const groupNotes = groupRaw.map(n => {
      const finalStep = n.stepOffset + shift;
      const y = (finalStep * (staffSpace / 2)) + staffSpace - (!isTreble ? (2 * staffSpace) : 0);
      return { ...n, finalStep, y, ySteps: finalStep };
    });
    return assignXLevels(groupNotes);
  };

  return {
    notes: [...processGroup(trebleNotesRaw, trebleShift, true), ...processGroup(bassNotesRaw, bassShift, false)],
    trebleLabel,
    bassLabel
  };
};

```

#### 2. Calibrated Timeline Write Mode Y-Snapping Algorithm

Calibrate mouse Y relative to the grand staff center (Middle C line) inside the hovered step bar, excluding the top 40px chord pill header:

$$\text{staffCenterY} = \text{barBoundingRect.top} + \text{headerPillHeight (40px)} + \left(\frac{\text{staffAreaHeight}}{2}\right)$$

$$\text{stepOffset} = \text{Math.round}\left(\frac{\text{staffCenterY} - \text{mouseY}}{\text{currentStaffSpace} / 2}\right)$$

```tsx
const snapTimelineGhostNote = (
  mouseY: number,
  barElement: HTMLElement,
  currentStaffSpace: number,
  keySignature: string,
  accidental: AccidentalOverride,
  lut: any[]
) => {
  const rect = barElement.getBoundingClientRect();
  const HEADER_PILL_HEIGHT = 40;
  const staffAreaHeight = rect.height - HEADER_PILL_HEIGHT;
  const staffCenterY = rect.top + HEADER_PILL_HEIGHT + (staffAreaHeight / 2);

  const stepHeight = currentStaffSpace / 2;
  const relativeY = staffCenterY - mouseY;
  const stepOffset = Math.round(relativeY / stepHeight);
  const snappedY = staffCenterY - (stepOffset * stepHeight);

  const { midiNote, accidental: calculatedAcc } = calculateWriteModePitch(
    stepOffset,
    keySignature,
    accidental,
    lut
  );

  return { stepOffset, snappedY, midiNote, calculatedAcc };
};

```

#### 3. Voice-Preserving Horizontal Arrow Navigation

```tsx
const handleVoicePreservingNavigation = (direction: 'left' | 'right') => {
  const currentStepIdx = selectedStepRef.current ?? 0;
  let targetStepIdx = currentStepIdx + (direction === 'right' ? 1 : -1);
  if (targetStepIdx < 0) targetStepIdx = 0;
  if (targetStepIdx > 11) targetStepIdx = 11;

  const currentBar = sequenceRef.current[currentStepIdx];
  const targetBar = sequenceRef.current[targetStepIdx];
  if (!targetBar) return;

  // 1. Sort current bar notes descending by pitch (top voice = index 0)
  const currentSorted = [...(currentBar?.notes || [])].sort((a, b) => b.note - a.note);
  
  // 2. Map active voice selection indices
  const activeVoiceIndices = currentSorted
    .map((n, idx) => (selectedNotes?.includes(n.note) ? idx : -1))
    .filter(idx => idx !== -1);

  // 3. Select corresponding voices in target bar
  const targetSorted = [...(targetBar.notes || [])].sort((a, b) => b.note - a.note);
  let newSelectedPitches: number[] = [];

  if (activeVoiceIndices.length > 0 && activeVoiceIndices.length < currentSorted.length) {
    newSelectedPitches = activeVoiceIndices
      .map(idx => targetSorted[idx]?.note)
      .filter((pitch): pitch is number => typeof pitch === 'number');
  } else {
    newSelectedPitches = targetSorted.map(n => n.note);
  }

  setSelectedStep(targetStepIdx);
  selectedStepRef.current = targetStepIdx;
  updateActiveNotes(targetBar.notes, true, false, newSelectedPitches);
  playPreviewNotes(newSelectedPitches.map(p => Tone.Frequency(p, "midi").toNote()), true);
};

```
