# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives

In the Chord Notator module (`src/plugins/chord-notator/`), the 12-bar timeline (`StepSequencer.tsx`) has layout, audio, and interaction bugs in Write Mode and note editing:

1. **Write Mode Ghost Note Y-Axis Mouse Offset Bug:** Ghost noteheads render inside the top chord pill header area (`h-10` / 40px) or offset ~5 note space units below the cursor position. This occurs because coordinate calculations were tied to the outer bar wrapper rather than the inner `.staff-canvas-area` container (`<div className="flex-1 relative w-full h-full staff-canvas-area">`). Ghost noteheads must be scoped **strictly inside the staff canvas area**, positioned relative to the staff center line ($Y = 0$, Middle C), and automatically suppressed when the cursor hovers over the top chord pill header area.


2. **Ottava (`8va`/`15ma`) Label Placement Bug:** Ottava markings currently render *to the left* of noteheads (`8va O`) instead of centered horizontally (`left: 50%`, `-translate-x-1/2`) *above* (treble `8va`/`15ma`) or *below* (bass `8vb`/`15mb`) the chord.


3. **Key Command Transposition Audio Sustain Bug:** Transposing selected notes via keyboard shortcuts (`ArrowUp`, `ArrowDown`, `Alt+ArrowUp`, etc.) triggers un-tracked `audioEngine.noteOn` calls without scheduling corresponding `releaseNote` timeouts. All transposition triggers must route through a strict 500ms preview helper (`playPreviewNotes`).


4. **Relocated Write Mode Toolbar:** The Write Mode accidental toolbar currently renders inside the timeline card, overlapping bars 1 and 2. It must be relocated **outside** the timeline card into the UI gap between `NotationCanvas` and `StepSequencer`.


5. **Voice-Preserving Navigation & Small-State Safeguard:** Left/Right arrow navigation between steps must preserve partial voice selections (ranked from top voice down), and editing interactions must be guarded OFF when the timeline is collapsed (`isExpanded === false`).

### Mathematical Formulas & Architectural Specifications

#### 1. Calibrated Staff Canvas Ghost Note Snapping Engine

Measure pointer Y strictly relative to the `.staff-canvas-area` bounding box (excluding the top 40px chord header completely):

$$\text{staffHeight} = \text{staffCanvasRect.height}$$

$$\text{staffCenterY} = \frac{\text{staffHeight}}{2}$$

$$\text{mouseY} = \text{clientY} - \text{staffCanvasRect.top}$$

If $\text{mouseY} < 0$ or $\text{mouseY} > \text{staffHeight}$ (cursor is in the top chord header or outside staff area), set `isOutOfBounds = true` and suppress/hide the ghost notehead.

Otherwise, calculate staff step offset and snapped Y position relative to the staff center line:

$$\text{stepHeight} = \frac{\text{currentStaffSpace}}{2}$$

$$\text{relativeY} = \text{staffCenterY} - \text{mouseY}$$

$$\text{stepOffset} = \text{Math.round}\left(\frac{\text{relativeY}}{\text{stepHeight}}\right)$$

$$\text{snappedY} = \text{staffCenterY} - (\text{stepOffset} \times \text{stepHeight})$$

```tsx
const snapTimelineGhostNote = (
  clientY: number,
  staffCanvasElement: HTMLElement,
  currentStaffSpace: number,
  keySignature: string,
  accidental: AccidentalOverride,
  lut: any[]
) => {
  const rect = staffCanvasElement.getBoundingClientRect();
  const mouseY = clientY - rect.top;

  // Suppress ghost note if pointer is outside the staff canvas area (e.g. in chord header)
  if (mouseY < 0 || mouseY > rect.height) {
    return { isOutOfBounds: true, stepOffset: 0, snappedY: 0, midiNote: 60, calculatedAcc: null };
  }

  const staffCenterY = rect.height / 2;
  const relativeY = staffCenterY - mouseY;
  const stepHeight = currentStaffSpace / 2;
  const stepOffset = Math.round(relativeY / stepHeight);
  const snappedY = staffCenterY - (stepOffset * stepHeight);

  const { midiNote, accidental: calculatedAcc } = calculateWriteModePitch(
    stepOffset,
    keySignature,
    accidental,
    lut
  );

  return { isOutOfBounds: false, stepOffset, snappedY, midiNote, calculatedAcc };
};

```

#### 4. Unified 500ms Audio Preview Engine (`playPreviewNotes`)

All preview triggers (mouse clicks, selection changes, Write Mode entry, and key command transpositions) must route strictly through `playPreviewNotes`:

```tsx
const activePreviews = useRef<Map<string, ReturnType<typeof setTimeout>>>(new Map());

const playPreviewNotes = (noteStrings: string[], interrupt: boolean = true, velocity: number = 80) => {
  if (interrupt) {
    activePreviews.current.forEach((timeoutId, noteStr) => {
      clearTimeout(timeoutId);
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
    });
    activePreviews.current.clear();
    try { audioEngine.releaseAll(); } catch(err) {}
  }

  const normalizedVelocity = velocity / 127;

  noteStrings.forEach(noteStr => {
    try { audioEngine.noteOn(noteStr, normalizedVelocity); } catch(err) {}
    const timeoutId = setTimeout(() => {
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
      activePreviews.current.delete(noteStr);
    }, 500); // Strict 500ms duration
    activePreviews.current.set(noteStr, timeoutId);
  });
};

```
