# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives

In the Chord Notator module (`src/plugins/chord-notator/`), expanding the 12-bar timeline (`StepSequencer.tsx`) in-situ currently exhibits visual layout bugs and lacks key interactive parity with the main notation canvas (`NotationCanvas.tsx`):

1. **In-Situ Layout Math & Clef Column Bugs:** Notehead vertical positioning (`n.y`) uses hardcoded step multipliers (`MINI_STAFF = 5`), causing vertical note squishing when expanded. The left brace/clef column is too narrow (`w-[45px]`), causing SMuFL clefs and braces to clip and overlap adjacent UI elements.


2. **Chord Card Audio Duration Bug:** Clicking a chord symbol pill plays a short preset decay note instead of sustaining the chord for as long as the mouse button is held down.


3. **Timeline Note Preview Audio Bug:** Selecting individual notes on the timeline triggers audio events with infinite/uncontrolled sustain instead of a fixed 500ms (1/4 note at 120 BPM) preview.


4. **Horizontal Voice-Preserving Navigation:** Pressing `ArrowLeft` or `ArrowRight` currently selects all notes in the destination chord. Navigation must preserve voice selections (ranked from top voice down) when moving between bars.


5. **Write Mode Parity:** Double-clicking the timeline staff does not activate note entry. Double-clicking must toggle Write Mode, displaying a purple ghost notehead (`SMuFL.noteheadBlack`) horizontally aligned with the bar center and vertically quantized to the mouse position, alongside an accidental toolbox (Flat, Natural, Sharp).

### Algorithms & Mathematical Specifications

#### 1. Dynamic Layout Formula (`computeMiniLayout`)

Refactor layout calculation to consume the active `staffSpace` parameter:

$$\text{stepHeight} = \frac{\text{staffSpace}}{2}$$

$$y = (\text{n.stepOffset} \times \text{stepHeight}) + \text{staffSpace} - (\text{isTreble} ? 0 : 2 \times \text{staffSpace})$$

```tsx
const computeMiniLayout = (rawNotes: any[], staffSpace: number) => {
  const NOTE_OFFSET_X_PX = staffSpace * 1.2;
  const PADDING_PX = 2;
  const ACC_WIDTH_PX = staffSpace * 1.2;

  const processGroup = (groupRaw: any[], isTreble: boolean) => {
    const groupNotes = groupRaw.map(n => ({
      ...n,
      ySteps: n.stepOffset,
      finalStep: n.stepOffset,
      y: (n.stepOffset * (staffSpace / 2)) + staffSpace - (!isTreble ? (2 * staffSpace) : 0)
    }));
    return assignXLevels(groupNotes);
  };

  return [...processGroup(trebleNotes, true), ...processGroup(bassNotes, false)];
};

```

#### 2. Voice-Preserving Horizontal Navigation Engine

When navigating between steps via `ArrowLeft` / `ArrowRight`, rank chord pitches in descending order (top voice = index 0):

```tsx
const handleVoicePreservingNavigation = (direction: 'left' | 'right') => {
  const currentStepIdx = selectedStepRef.current ?? 0;
  let targetStepIdx = currentStepIdx + (direction === 'right' ? 1 : -1);
  if (targetStepIdx < 0) targetStepIdx = 0;
  if (targetStepIdx > 11) targetStepIdx = 11;

  const currentBar = sequenceRef.current[currentStepIdx];
  const targetBar = sequenceRef.current[targetStepIdx];
  if (!targetBar) return;

  // 1. Sort current bar notes descending by pitch
  const currentSorted = [...(currentBar?.notes || [])].sort((a, b) => b.note - a.note);
  
  // 2. Identify active voice indices
  const activeVoiceIndices = currentSorted
    .map((n, idx) => (selectedNotes?.includes(n.note) ? idx : -1))
    .filter(idx => idx !== -1);

  // 3. Map voice indices onto target bar
  const targetSorted = [...(targetBar.notes || [])].sort((a, b) => b.note - a.note);
  let newSelectedPitches: number[] = [];

  if (activeVoiceIndices.length > 0 && activeVoiceIndices.length < currentSorted.length) {
    // Preserve voice indices (guarded by target pitch count)
    newSelectedPitches = activeVoiceIndices
      .map(idx => targetSorted[idx]?.note)
      .filter((pitch): pitch is number => typeof pitch === 'number');
  } else {
    // If entire chord was selected (or no selection), select full target chord
    newSelectedPitches = targetSorted.map(n => n.note);
  }

  setSelectedStep(targetStepIdx);
  selectedStepRef.current = targetStepIdx;
  updateActiveNotes(targetBar.notes, true, false, newSelectedPitches);
  playPreviewNotes(newSelectedPitches.map(p => Tone.Frequency(p, "midi").toNote()), true);
};

```

#### 3. 500ms Audio Preview Helper

```tsx
const activePreviews = useRef<Map<string, ReturnType<typeof setTimeout>>>(new Map());

const playPreviewNotes = (noteStrings: string[], interrupt: boolean = true) => {
  if (interrupt) {
    activePreviews.current.forEach((timeoutId, noteStr) => {
      clearTimeout(timeoutId);
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
    });
    activePreviews.current.clear();
  }

  noteStrings.forEach(noteStr => {
    try { audioEngine.noteOn(noteStr, uiVelocityRef.current / 127); } catch(err) {}
    const timeoutId = setTimeout(() => {
      try { audioEngine.releaseNote(noteStr); } catch(err) {}
      activePreviews.current.delete(noteStr);
    }, 500); // 1/4 note at 120 BPM
    activePreviews.current.set(noteStr, timeoutId);
  });
};

```
