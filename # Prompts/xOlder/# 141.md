
# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives
In the Chord Notator module (`src/plugins/chord-notator/`), the 12-bar timeline (`StepSequencer.tsx`) requires mathematical alignment and history stack integration to resolve two critical issues:

1. **Ghost Note vs. Placed Note Pitch Offset (3rd Offset Bug):** When clicking in Write Mode, the placed note appears a musical 3rd (2 staff steps) above the ghost notehead preview. This occurs because `computeMiniLayout` applies a `+ staffSpace` offset ($2 \times \frac{\text{staffSpace}}{2}$) to treble notes when computing `y`, whereas `snapTimelineGhostNote` calculated `snappedY` without this offset. The ghost note snapping formula must match `computeMiniLayout` pixel-for-pixel.
2. **Timeline Undo / Redo Failure:** Pressing `Cmd+Z` / `Ctrl+Z` does not undo sequence edits because `StepSequencer.tsx` lacks an internal history stack (`seqUndoStack` / `seqRedoStack`). Sequence mutations (note insertion, deletion, transpositions, clearing) must save history snapshots and respond to undo/redo shortcuts and `APP_HISTORY` events.
3. **Relocated Write Mode Toolbar:** The Write Mode accidental toolbar must render **outside** the timeline card in `index.jsx`, positioned in the layout space between `NotationCanvas` and `StepSequencer`.

## 2. Technical Decisions & Architectural Fixes

### Component State & History Architecture (`StepSequencer.tsx` & `index.jsx`)
* **`seqUndoStack` (`useRef<any[][]>`):** History stack storing deep-cloned snapshots of `sequence` (max 50 states).
* **`seqRedoStack` (`useRef<any[][]>`):** Stack storing undone states cleared on new commits.
* **`isWriteMode` & `accidentalOverride`:** Lifted/shared state rendering the accidental toolbar in `index.jsx` above `StepSequencer`.
* **`currentStaffSpace`:** `isExpanded ? 11 : 5` (px per staff space).

### Mathematical Formulas & Architectural Specifications

#### 1. Pixel-Identical Ghost Note Snapping Math
To ensure the ghost notehead renders at the exact same pixel position as the placed note, `snapTimelineGhostNote` MUST incorporate the exact `computeMiniLayout` offset formula:

$$\text{mouseY} = \text{clientY} - \text{staffCanvasRect.top}$$
$$\text{staffCenterY} = \frac{\text{staffCanvasRect.height}}{2}$$
$$\text{relativeY} = \text{staffCenterY} - \text{mouseY}$$
$$\text{stepHeight} = \frac{\text{currentStaffSpace}}{2}$$
$$\text{stepOffset} = \text{Math.round}\left(\frac{\text{relativeY}}{\text{stepHeight}}\right)$$

Calculate target MIDI pitch using `calculateWriteModePitch(stepOffset, keySignature, accidental, lut)`.

Determine whether target pitch is treble ($\text{midiNote} \ge 60$):

$$\text{layoutY} = (\text{stepOffset} \times \text{stepHeight}) + \text{currentStaffSpace} - (\text{isTreble} ? 0 : 2 \times \text{currentStaffSpace})$$
$$\text{snappedY} = \text{staffCenterY} - \text{layoutY}$$

```tsx
export const snapTimelineGhostNote = (
  clientY: number,
  staffCanvasElement: HTMLElement,
  currentStaffSpace: number,
  keySignature: string,
  accidental: AccidentalOverride,
  lut: any[]
) => {
  const rect = staffCanvasElement.getBoundingClientRect();
  const mouseY = clientY - rect.top;

  if (mouseY < 0 || mouseY > rect.height) {
    return { isOutOfBounds: true, stepOffset: 0, snappedY: 0, midiNote: 60, calculatedAcc: null };
  }

  const staffCenterY = rect.height / 2;
  const relativeY = staffCenterY - mouseY;
  const stepHeight = currentStaffSpace / 2;
  const stepOffset = Math.round(relativeY / stepHeight);

  const { midiNote, accidental: calculatedAcc } = calculateWriteModePitch(
    stepOffset,
    keySignature,
    accidental,
    lut
  );

  const isTreble = midiNote >= 60;
  const layoutY = (stepOffset * stepHeight) + currentStaffSpace - (isTreble ? 0 : 2 * currentStaffSpace);
  const snappedY = staffCenterY - layoutY;

  return { isOutOfBounds: false, stepOffset, snappedY, midiNote, calculatedAcc };
};

```

#### 2. Sequence History Machine (`commitSeqState`, `undoSeq`, `redoSeq`)

```tsx
const seqUndoStack = useRef<any[][]>([]);
const seqRedoStack = useRef<any[][]>([]);

const commitSeqState = () => {
  seqUndoStack.current.push(JSON.parse(JSON.stringify(sequenceRef.current)));
  seqRedoStack.current = [];
  if (seqUndoStack.current.length > 50) seqUndoStack.current.shift();
};

const undoSeq = () => {
  if (seqUndoStack.current.length > 0) {
    seqRedoStack.current.push(JSON.parse(JSON.stringify(sequenceRef.current)));
    const prev = seqUndoStack.current.pop()!;
    setSequence(prev);
    if (selectedStepRef.current !== null) {
      updateActiveNotes(prev[selectedStepRef.current]?.notes || [], true);
    }
  }
};

const redoSeq = () => {
  if (seqRedoStack.current.length > 0) {
    seqUndoStack.current.push(JSON.parse(JSON.stringify(sequenceRef.current)));
    const next = seqRedoStack.current.pop()!;
    setSequence(next);
    if (selectedStepRef.current !== null) {
      updateActiveNotes(next[selectedStepRef.current]?.notes || [], true);
    }
  }
};

```
