# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives

In the Chord Notator module (`src/plugins/chord-notator/`), the step sequencer timeline currently renders interactive mini-staff notation with direct note clicking and marquee rectangle selections. However, due to the small vertical scale of the mini-staff, note click targets are too tight for reliable editing, and marquee drag events frequently interfere with the option+click-and-drag chord copying functionality on the chord symbol pills.

**Key Objectives:**

1. **Disable Mini-Timeline Editing:** Completely remove marquee selection drag handlers and individual note click hitboxes from the mini-staff timeline in `StepSequencer.tsx`. Clicking anywhere on a step bar or chord pill will strictly handle bar selection or option+drag chord copying without marquee or note-hitbox interference.


2. **Add Expand Control:** Place a small expand button in the top-left corner of the timeline card container.


3. **Modal/Expanded Notation Editor:** When clicked, launch an expanded notation timeline view (large notation system mirroring `NotationCanvas.tsx`).


4. **Enable Editing in Expanded State:** Full interactive notation editing (marquee selection, note clicking, transposition shortcuts, write mode) will activate *only* within this expanded view state.

## 2. Technical Decisions & Dependencies

### Libraries & Components

* **Icons:** `lucide-react` (`Maximize2`, `Minimize2`, `X`, `Copy`, `Trash2`, `Keyboard`).


* **Audio Engine:** Centralized `audioEngine` instance (`src/plugins/chord-notator/audio/engine.ts`) with `Tone.Frequency` string conversions.


* **State Management:** `MIDIProvider` context hooks (`useMidi()`) managing `sequence`, `setSequence`, `updateActiveNotes`, and `selectedNotes`.



### Architectural Approach & Pseudo-Code

#### 1. Disabling Mini-Timeline Marquee & Direct Note Editing (`StepSequencer.tsx`)

Remove pointer capture / drag state tracking on `seqCanvasRef` and strip the transparent `data-seq-note` hitboxes from the mini note rendering loop.

```tsx
// BEFORE (StepSequencer.tsx):
// Canvas marquee pointer capture intercepted all clicks across bars[cite: 2].
<div ref={seqCanvasRef} onPointerDown={handlePointerDown} ...>

// AFTER:
// Scroll container retains pure native horizontal scrolling without marquee capture[cite: 2].
<div ref={seqCanvasRef} className="flex-1 flex overflow-x-auto ...">

```

#### 2. Top-Left Timeline Expand Button

Position a button at `top-2 left-2` inside the `StepSequencer` container:

```tsx
<button
  onClick={() => setIsExpanded(true)}
  title="Expand Notation Timeline"
  className="w-7 h-7 rounded border border-gray-200 dark:border-gray-800 hover:border-[#aa3bff] hover:text-[#aa3bff] text-gray-400 dark:text-gray-500 flex items-center justify-center transition-colors bg-white dark:bg-[#111] cursor-pointer"

  <Maximize2 size={13} />
</button>

```

#### 3. Expanded Timeline Editor Modal Logic

When `isExpanded === true`, render an overlay modal containing a large-scale `NotationCanvas` bound to the active sequence step:

```tsx
{isExpanded && (
  <div className="fixed inset-0 z-50 bg-black/80 backdrop-blur-sm flex flex-col items-center justify-center p-6 animate-fadeIn">
    <div className="bg-white dark:bg-[#111] rounded-2xl border border-gray-200 dark:border-gray-800 shadow-2xl p-6 w-full max-w-[1020px] flex flex-col gap-4 relative">
      {/* Header Controls: Step Selector Pills + Close Button */}
      <div className="flex items-center justify-between w-full border-b pb-4 border-gray-200 dark:border-gray-800">
        <div className="flex items-center gap-2">
          <button onClick={() => setIsExpanded(false)} className="p-2 rounded-full hover:bg-gray-100 dark:hover:bg-gray-800">
            <Minimize2 size={18} />
          </button>
          <h2 className="text-sm font-bold uppercase tracking-wider text-gray-700 dark:text-gray-300">
            Expanded Timeline Editor
          </h2>
        </div>
        
        {/* Step Navigation Bar */}
        <div className="flex items-center gap-1.5 overflow-x-auto">
          {sequence.map((bar, idx) => (
            <button
              key={idx}
              onClick={() => handleSelectExpandedStep(idx)}
              className={`px-3 py-1 rounded-full text-xs font-bold ${
                selectedStep === idx ? 'bg-[#aa3bff] text-white' : 'bg-gray-100 dark:bg-gray-800 text-gray-600 dark:text-gray-400'
              }`}
            >
              Bar {idx + 1}: {bar.symbol || '-'}
            </button>
          ))}
        </div>
      </div>

      {/* Large Interactive Canvas */}
      <div className="w-full flex justify-center">
        <NotationCanvas />
      </div>
    </div>
  </div>
)}

```

## 3. Implementation Phases

### Phase 1: Disable Mini-Timeline Direct Editing & Marquee — 🔘

* **Instructions:**
1. Remove `onPointerDown`, `onPointerMove`, `onPointerUp`, and `onPointerLeave` handlers from `seqCanvasRef` in `StepSequencer.tsx`.


2. Remove `marqueeRef` and drag tracking logic (`dragTracker`) from `StepSequencer.tsx`.


3. Remove the isolated note hitbox `div` (`data-seq-note`) inside `renderedNotes.map(...)` so that clicking on notes in the mini-staff passes directly to the parent bar/pill event handler.


4. Verify that Option + Click and Drag on chord symbol pills copies chords across steps without visual artifacts or accidental note selections.
