# Product Requirements Prompt (PRP) — Bulletproof Timeline Hitboxes 🔘

## 1. Project Context & Objectives
The previous attempt to fix the timeline note selection failed because CSS bounding boxes (especially from absolute-positioned ledger lines and accidentals) are still overlapping and intercepting clicks. To permanently solve this, we will implement an **Isolated Hitbox Pattern**. We will strip all interactivity from the visual elements and inject a dedicated, perfectly-sized, invisible hitbox `<div>` directly over each notehead with an ultra-high z-index.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/plugins/chord-notator/components/StepSequencer.tsx`.
* **Hitbox Geometry:** A `w-6 h-6` (24x24px) absolute-positioned invisible `div`, centered exactly on the notehead coordinates using `-translate-x-1/2 -translate-y-1/2`.
* **Event Delegation:** `pointer-events-none` will be strictly applied to the note's root wrapper, while `pointer-events-auto` will be explicitly applied to the new hitbox.

## 3. Implementation Phases

### Phase 1: Isolated Hitbox Injection (`StepSequencer.tsx`) — 🔘
* **Objective:** Replace unreliable DOM-element clicks with a mathematically precise invisible hitbox.
* **Instructions:**
  1. Locate the `renderedNotes.map((n, i) => { ... return ( <div ...> ) })` loop (around line 431).
  2. On the root wrapper `<div key={i} className="absolute z-10...">`, explicitly add `pointer-events-none` to its class list.
  3. Remove **any** `onPointerDown`, `cursor-pointer`, or `pointer-events-auto` classes from the notehead `<span>`, accidentals, or ledger lines. They must be purely visual.
  4. **Inject the Hitbox:** Add this new `<div>` as the *last child* inside the note's root wrapper:
     ```javascript
     {/* ISOLATED HITBOX */}
     <div 
       data-seq-note={n.note}
       data-seq-step={idx}
       className="absolute top-1/2 left-1/2 w-6 h-6 -translate-x-1/2 -translate-y-1/2 cursor-pointer pointer-events-auto z-50 rounded-full"
       onPointerDown={(e) => {
         e.preventDefault();
         e.stopPropagation(); // CRITICAL: Prevents the chord pill from stealing the click
         
         setSelectedStep(idx);
         if (selectedStepRef) selectedStepRef.current = idx;
         
         let newSelection = [n.note];
         if (e.metaKey || e.ctrlKey || e.shiftKey) {
            const isSelected = selectedNotes?.includes(n.note);
            newSelection = isSelected 
                ? (selectedNotes || []).filter(p => p !== n.note) 
                : [...(selectedNotes || []), n.note];
         }
         
         updateActiveNotes(bar.notes, true, false, newSelection);
         
         try { Tone.context.resume(); } catch(err){}
         try { audioEngine.releaseAll(); } catch(err){}
         const noteStr = Tone.Frequency(n.note, "midi").toNote();
         try { audioEngine.noteOn(noteStr, uiVelocity / 127); } catch(err){}
       }}
     />
     ```
* **TDD Checkpoint:** * **Test Case 1:** [Given a dense chord on the timeline, When clicking the visual center of the bottom note, Assert the hitbox successfully intercepts the click and `updateActiveNotes` receives the bottom note's pitch].
  * **Status Update:** "Transition Phase status to 🔵 Active. Inject the isolated hitboxes. Once complete, update to ✅ Completed."
