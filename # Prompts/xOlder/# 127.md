# Product Requirements Prompt (PRP) — Viewport Vertical Scroll Fix 🔘

## 1. Project Context & Objectives
The newly implemented 12-bar sequencer viewport correctly scrolls horizontally, but is unintentionally triggering a vertical scrollbar due to minor pixel overflows from internal elements (like ledger lines or padding). We need to explicitly hide the vertical overflow on the scrolling container to keep the UI clean.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/plugins/chord-notator/components/StepSequencer.tsx`.
* **CSS Fix:** We will append Tailwind's `overflow-y-hidden` utility class to the specific container managing the horizontal scroll.

## 3. Implementation Phases

### Phase 1: Explicit Vertical Overflow Hiding (`StepSequencer.tsx`) — 🔘
* **Objective:** Force the browser to suppress the vertical scrollbar on the sequencer track.
* **Instructions:**
  1. Locate the container wrapping the `sequence.map` loop (implemented in the previous phase):
     ```javascript
     <div className="flex-1 flex overflow-x-auto scrollbar-thin ...">
     ```
  2. Add `overflow-y-hidden` to the class list:
     ```javascript
     <div className="flex-1 flex overflow-x-auto overflow-y-hidden scrollbar-thin ...">
     ```
* **TDD Checkpoint:** * **Test Case 1:** [Given the StepSequencer is rendered, Assert the horizontal track container possesses both `overflow-x-auto` and `overflow-y-hidden` classes].
  * **Status Update:** "Transition Phase status to 🔵 Active. Apply the CSS fix. Once visually confirmed, update to ✅ Completed."

## 4. Final Review & Validation
* **Technical Audit:** Pan the sequencer horizontally to ensure no high ledger lines or low notes are aggressively clipped by the new hidden overflow. If minor clipping occurs, increase the container's vertical padding slightly rather than restoring the scrollbar.
* **Status Reconciliation:** Verify all sub-phases match ✅ or ❌ before updating top-level status to ✅.
