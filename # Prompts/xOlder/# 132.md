# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives

In the Chord Notator module (`src/plugins/chord-notator/`), expanding the 12-bar timeline (`StepSequencer.tsx`) in-situ currently exhibits two primary visual/layout bugs:

1. **Vertical Note Squishing Bug:** The layout calculation engine (`computeMiniLayout`) and inline CSS positioning rely on a hardcoded constant (`MINI_STAFF = 5`). When the timeline expands to a larger card height (~320px) with larger staff line spacing, the layout engine continues calculating note vertical positions (`n.y`) using `5px` step units. This causes noteheads to clump together in a tiny vertical space in the middle of the expanded staff.


2. **Cramped Brace/Clef Column Bug:** The left clef/brace column is fixed at `w-[45px]`. When expanded, the SMuFL brace (`\uE000`) and treble/bass clefs scale up proportionally with staff space, causing the brace to overflow the left container border and collide with adjacent UI elements.



**Key Objectives:**

1. **Dynamic Layout Math Scaling:** Refactor `computeMiniLayout` and all inline style calculations in `StepSequencer.tsx` to dynamically use `currentStaffSpace` (`5px` collapsed, `11px` expanded).


2. **Dynamic Left Column Width:** Expand the left brace/clef column from `w-[45px]` (collapsed) to `w-[75px]` (expanded), adjusting horizontal offsets so the brace and clefs render with clean breathing room.


3. **Small-State Editing Safeguard:** Turn OFF marquee rectangle selection, individual note hitboxes, and write-mode entries when collapsed. Preserve Option + Click & Drag chord copying across bars.


4. **Expanded Interactive Editing:** Enable marquee selection, note hitboxes, Arrow key note transpositions, and double-click note entry *only* when `isExpanded === true`.

## 2. Technical Decisions & Dependencies

* **`isExpanded` (boolean):** Local state in `StepSequencer.tsx` toggled by the top-left expand button (`Maximize2` / `Minimize2` from `lucide-react`).

* **`clefColumnWidth` (string):** `isExpanded ? 'w-[75px]' : 'w-[45px]'`.
