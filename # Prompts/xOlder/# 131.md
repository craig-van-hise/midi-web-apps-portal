
# Product Requirements Prompt (PRP) — [Status Marker] 🔘

## 1. Project Context & Objectives
In the Chord Notator module (`src/plugins/chord-notator/`), the 12-bar timeline (`StepSequencer.tsx`) currently has active note hitboxes and marquee box selection enabled in its default compact height (`MINI_STAFF = 5`). Because the staff lines are so small, clicking individual notes is error-prone, and marquee drag gestures conflict with Option + Click and Drag chord copying on the chord symbol pills.

**Key Objectives:**
1. **Disable Small-State Editing:** Turn OFF marquee selection drag, note hitboxes, and double-click entry in `StepSequencer.tsx` when the timeline is in its default small state. Keep Option + Click & Drag chord copying and bar selection fully active.
2. **Top-Left Expand Button:** Place a compact expand toggle button in the top-left corner of the timeline card.
3. **In-Situ Timeline Expansion:** Expanding the timeline increases the card container height (e.g., from 140px to ~300px) and scales the timeline staff space across all bars continuously. The 12-bar horizontal sequence layout remains unified and scrollable.
4. **Conditional Editing Activation:** Enable full notation editing (marquee box selection, note click selection, Arrow key note transpositions, double-click note write mode) *only* when the timeline is in the expanded state.

---

## 2. Technical Decisions & Dependencies

### Component State & Props
* **`isExpanded` (boolean):** Local state in `StepSequencer.tsx` toggled by the expand button in the top-left corner.
* **Dynamic Staff Scale (`miniStaff`):**
  * **Collapsed State (`isExpanded === false`):** `STAFF_SPACE = 5` (140px timeline card height). Notation editing handlers disabled.
  * **Expanded State (`isExpanded === true`):** `STAFF_SPACE = 10` or `12` (~300px timeline card height). Notation editing handlers enabled across all 12 bars.
* **Icons:** `Maximize2` and `Minimize2` from `lucide-react`.

### Algorithm & Interaction Rules

#### A. Collapsed vs. Expanded Drag Guard (`StepSequencer.tsx`)
```tsx
const handlePointerDown = (e: React.PointerEvent) => {
  if (e.button !== 0) return;
  // STRICT GUARD: Marquee and note selection drag ONLY active when timeline is expanded
  if (!isExpanded) return;

  const target = e.target as HTMLElement;
  if (target.closest('button') || target.closest('[data-step-index]')) return;
  
  // Proceed with marquee rectangle drag initialization...
};

```

#### B. In-Situ Responsive Timeline Layout

```tsx
// Dynamic staff space computation based on expand state
const currentStaffSpace = isExpanded ? 11 : 5;
const containerHeightClass = isExpanded ? 'h-[320px]' : 'h-[140px]';

// Top-Left Expand Toggle Button
<button
  onClick={() => setIsExpanded(prev => !prev)}
  title={isExpanded ? "Collapse Timeline" : "Expand Timeline"}
  className="absolute top-2 left-2 z-30 p-1.5 rounded-md border border-gray-200 dark:border-gray-800 bg-white/90 dark:bg-[#111]/90 hover:border-[#aa3bff] hover:text-[#aa3bff] text-gray-400 dark:text-gray-500 transition-colors shadow-sm cursor-pointer"
>
  {isExpanded ? <Minimize2 size="{13}"/> : <Maximize2 size="{13}"/>}
</button>

```
