# Product Requirements Prompt (PRP) — Timeline Direct Note Manipulation 🔘

## 1. Project Context & Objectives
We are enabling direct note manipulation on the `StepSequencer` timeline. To avoid duplicating the complex transformation logic found in `NotationCanvas`, we will utilize a Proxy Selection Pattern. Clicking a mini-note on the timeline will trigger the selection of that bar, push its notes to the global engine, and command the main canvas to highlight *only* that specific pitch. Any subsequent transformations (e.g., using Arrow keys) will utilize the existing bi-directional sync to instantly reflect the edits back on the timeline.

## 2. Technical Decisions & Dependencies
* **Target Files:** `src/plugins/chord-notator/components/NotationCanvas.tsx`, `src/plugins/chord-notator/midi/MIDIProvider.tsx`, and `src/plugins/chord-notator/components/StepSequencer.tsx`.
* **State Bridge:** We will extend the `updateActiveNotes` context function to accept an optional `targetSelection?: number[]` parameter.
* **Hitboxes:** The static SVG noteheads in the `StepSequencer` will receive pointer events. We will use `e.stopPropagation()` to ensure clicking a note doesn't trigger the parent chord pill's drag/select logic.
