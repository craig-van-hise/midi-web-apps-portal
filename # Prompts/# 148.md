# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives

### 1.1 Summary of Objectives

We have validated that the Write Mode Ottava (`8va`/`15ma`/`8vb`/`15mb`) pitch calculation offset bug is resolved and verified. However, two critical functional issues remain in the primary notation editor (`src/plugins/chord-notator/components/NotationCanvas.tsx`):

1. **Main Notation Undo/Redo Is Non-Functional:** Pressing `Cmd+Z` / `Ctrl+Z` (Undo) or `Cmd+Shift+Z` / `Ctrl+Y` (Redo) on the main notation canvas does nothing. The internal history stacks (`undoStack` and `redoStack`) fail to restore previous canvas states due to shallow object cloning, missing synchronous React re-render triggers (`forceUpdate()`), and case-sensitive event listeners.


2. **Write Mode New Note Auto-Selection Bug:** When inserting a new note via mouse click in Write Mode (`Shift+W`) on the main notation canvas, the newly added note appears unselected. This creates friction in user workflow, as users must manually click the newly inserted note before transposing it with Arrow Up/Down keys. In contrast, adding a note in the step sequencer (`StepSequencer.tsx`) correctly auto-selects the new note.



### 1.2 Current Technical State & Root Cause Analysis

* **Why Undo/Redo Does Nothing (`NotationCanvas.tsx`):**
* **Missing `forceUpdate()` Trigger:** `undo()` (lines 331–341) and `redo()` (lines 343–353) mutate `activeNotes.current` and call `updateSpellings()` and `recalculateLayout()`, but omit calling `forceUpdate()`. Because `renderedNotes` state updates inside `recalculateLayout()` may be bailed out by React if object references appear similar or if asynchronous render batches coalesce, React fails to synchronously re-render the canvas.


* **Shallow Copy Snapshot Corruption:** `commitState()` (line 99) currently executes `undoStack.current.push(activeNotes.current.map(n => ({ ...n })))`. Shallow copying array elements allows subsequent nested property mutations or spelling re-evaluations to corrupt stored snapshots in place.


* **Case-Sensitive `APP_HISTORY` Event Listener:** In `handleHistory` (line 632), the action parser uses case-sensitive matching (`switch (action)` expecting exact uppercase `'UNDO'` / `'REDO'`). If a toolbar or menu dispatches lowercase or mixed-case action strings, the handler ignores the event.


* **Keyboard Shortcut Event Priority:** In `handleKeyDown` (lines 784–796), `Cmd+Z` / `Ctrl+Z` checks lack `e.stopPropagation()`, allowing event bubbling or browser default history handlers to interfere.




* **Why Write Mode Notes Are Not Auto-Selected (`NotationCanvas.tsx`):**
* In `handlePointerDown` when `isWriteMode.current === true` (lines 705–726), after pushing the new note to `activeNotes.current`, the function executes `return; // Early return to prevent selection logic` without updating `selectedNoteIds.current` or calling `setSelectedNotes?.([targetMidiNote])`. Consequently, `selectedNoteIds.current.size === 0`, and the notehead renders as unselected (`#000000` instead of `#aa3bff`).

## 2. Technical Decisions & Dependencies

### 2.1 Architectural Decisions & Zero-Drift Alignment

* **Strict Deep-Cloning for History Snapshots:** We standardize all stack pushes and pops across `commitState()`, `undo()`, and `redo()` to use `JSON.parse(JSON.stringify(...))`. This guarantees zero reference leakage between historical canvas snapshots and active state.


* **Synchronous Re-Render Enforcement:** Both `undo()` and `redo()` must execute `forceUpdate()` as their final statement to force an immediate React render cycle whenever history is traversed.
* **Parity with Step Sequencer Auto-Selection:** We clone the auto-selection pattern from `StepSequencer.tsx`. Immediately after a note is inserted in Write Mode on `NotationCanvas.tsx`, we clear existing selections, add the newly generated note ID to `selectedNoteIds.current`, set `lastSelectedNoteId.current`, and invoke `setSelectedNotes?.([targetMidiNote])`.



### 2.2 Pseudo-Code Specifications

#### Undo/Redo & Event Normalization Pseudo-Code

```typescript
const commitState = () => {
  undoStack.current.push(JSON.parse(JSON.stringify(activeNotes.current)));
  redoStack.current = []; // Clear redo stack on new action
  if (undoStack.current.length > 50) undoStack.current.shift(); // Max 50 states
};

const undo = () => {
  if (undoStack.current.length > 0) {
    redoStack.current.push(JSON.parse(JSON.stringify(activeNotes.current)));
    activeNotes.current = undoStack.current.pop() || [];
    selectedNoteIds.current.clear();
    chordIdentityRef.current.isActive = false;
    updateSpellings();
    updateActiveNotes?.([...activeNotes.current]);
    recalculateLayout();
    forceUpdate(); // MANDATORY: Force synchronous React re-render
  }
};

const redo = () => {
  if (redoStack.current.length > 0) {
    undoStack.current.push(JSON.parse(JSON.stringify(activeNotes.current)));
    activeNotes.current = redoStack.current.pop() || [];
    selectedNoteIds.current.clear();
    chordIdentityRef.current.isActive = false;
    updateSpellings();
    updateActiveNotes?.([...activeNotes.current]);
    recalculateLayout();
    forceUpdate(); // MANDATORY: Force synchronous React re-render
  }
};

```
